Matplotlib 可视化综合练习
本项目包含任务 1～任务 13 共 13 份 Python 代码，全部基于基础matplotlib、numpy实现图表绘制，为数据分析可视化课程配套练习。

任务清单
任务 1：绘制不同风格水平线、垂直线
任务 2：正弦曲线，设置标题、坐标轴、自定义刻度
任务 3：格式化字符串绘制直线、多条抛物线
任务 4：正弦、余弦曲线，图例各项参数设置
任务 5：文本、标注、网格线综合设置
任务 6：单系列柱状图 —— 铁路营业里程
任务 7：多系列分组柱状图 —— 就业人员数据
任务 8：堆积柱状图 —— 各类运输旅客周转量
任务 9：雷达图 —— 直辖市软件项目收入
任务 10：散点图 —— 广告投入与销售额（自建模拟数据）
任务 11：气泡图 —— 广告投入、销售额、投入产出比（自建模拟数据）
任务 12：面积图 —— 国内游客人次统计
任务 13：圆环图 —— 高等教育毕业生人数占比
